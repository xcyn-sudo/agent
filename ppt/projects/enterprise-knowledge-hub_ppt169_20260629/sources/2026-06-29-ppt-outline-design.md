## 1. 设计概览

### 1.1 PPT定位

面向中高层管理者、客户决策者的汇报型PPT，采用**故事线驱动型**结构，叙事逻辑为：

```
政策东风 → 企业痛点 → 解决方案 → 技术硬实力 → 落地效果 → 未来展望
```

### 1.2 关键参数

| 参数 | 值 |
|------|-----|
| 总页数 | 21页 |
| 预计演讲时长 | 20-25分钟 |
| 配色基调 | 深色科技蓝 + 渐变紫，关键页深色背景，文字页浅色背景 |
| 动效风格 | 流畅科技感，每页动效控制在2-4秒 |
| 数据来源 | 《软件需求规格说明书 v2.0》、《系统概要设计说明书 v1.0》、网络搜索（中国AI政策） |

### Slide 10 — 技术栈选型详解

**内容布局：** 左右分栏

**左侧 — 核心技术选型及理由：**

| 层级 | 选型 | 选型理由 |
|------|------|---------|
| 前端 | Vue3 + Vite | 生态成熟、SSE支持好、团队熟悉 |
| 后端 | Spring Boot 3 | 企业级生态、MyBatis-Plus、安全框架完善 |
| LLM | Ollama(本地) + DeepSeek(备用) | 数据不出企业，本地qwen3做主链路，DeepSeek做熔断降级 |
| 向量库 | ChromaDB | 轻量部署、HTTP API、适合企业内网 |
| 检索引擎 | 语义 + BM25 混合 | 语义理解+关键词精确匹配互补 |
| 权限 | ABAC五维度 | 角色+部门+密级+职级+时间，满足等保2.0 |

**右侧 — 关键设计决策：**

- 🏠 **数据不出企业**：全链路内网部署，LLM本地推理
- 🔌 **Provider可切换**：策略模式抽象LLM/Embedding，不绑定单一厂商
- ⚡ **全链路异步**：文档处理事件驱动，不阻塞用户操作
- 🔄 **断点续传**：数据同步失败有DLQ死信队列+3次退避重试

**动效设计：** 左右内容分别从两侧滑入

**数据来源：** 《系统概要设计说明书 v1.0》第2.3节 核心设计模式、第4章 技术架构设计

| 时间戳/CDC捕获变更，不对源系统做全表扫描 | 质量不合格自动阻断+告警，脏数据不入库 | Spring Event异步管道，文档上传即返回不阻塞 |

**动效设计：**

- 数据流从左到右依次点亮每个处理节点
- "合格→放行"用绿色脉冲、"不合格→阻断"用红色闪烁
- 最后三个存储节点同时点亮，连线用粒子流动效果

**数据来源：** 《软件需求规格说明书 v2.0》第4.2节 数据流架构图、《系统详细设计说明书 v1.0》第11-14章

## 8. 动效设计总规范

### 8.1 配色方案

| 用途 | 色值 | 说明 |
|------|------|------|
| 主色 | #1A73E8 (科技蓝) | 标题、主按钮、重点标注 |
| 辅色 | #7C4DFF (紫) | 渐变点缀、AI感 |
| 成功/正向 | #00C853 (绿) | 改善指标、通过状态 |
| 警告/拒绝 | #FF1744 (红) | 阻断、拒绝、下降 |
| 深色背景 | #0D1117 → #1A1F36 | 封面、架构页 |
| 浅色背景 | #F5F7FA | 文字详情页 |
| 文字主色 | #FFFFFF (深色底) / #1F2937 (浅色底) | — |

### 8.2 动效节奏原则

1. **封面/转场页**：动效2-3秒，建立氛围
2. **数据冲击页**：核心数字动画1-1.5秒，辅助元素1秒内完成
3. **技术架构页**：分层构建动画3-4秒（展示层次感需要时间）
4. **数据流页**：粒子流动持续2-3秒，循环播放
5. **列表/表格页**：逐行动画总时长控制在2秒内

### 8.3 过渡动画

- 页间切换统一使用**平滑过渡（Morph）**，同元素跨页自动变形衔接
- 避免使用花哨的翻页/百叶窗效果，保持专业感
