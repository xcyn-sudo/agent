## 1. 统计卡片扩展（★）

### 1.1 新增卡片

- [ ] 新增「今日点赞」统计卡片（数据源：`todayPositiveCount`）
- [ ] 卡片显示图标（👍）+ 数字 + 标签文字「今日点赞」
- [ ] 新增「今日点踩」统计卡片（数据源：`todayNegativeCount`）
- [ ] 卡片显示图标（👎）+ 数字 + 标签文字「今日点踩」
- [ ] 新增「满意度」统计卡片（数据源：`satisfactionRate`）
- [ ] 卡片显示图标（😊/⭐）+ 百分比数值 + 标签文字「满意度」

### 1.2 卡片布局

- [ ] 卡片布局从 4 列调整为 7 列（或 4+3 两行，或自适应 grid）
- [ ] P1 的 4 个卡片保持不变（今日问答、今日新增、文档总数、用户总数）
- [ ] 新增 3 个卡片放在第二行，或与原有卡片同行（使用 `el-row` + `el-col`）
- [ ] 满意度卡片使用条件颜色：≥80% 绿色，50%-80% 橙色，<50% 红色

## 2. ECharts 图表升级

### 2.1 问答趋势折线图升级

- [ ] 折线图配置新增「满意度」数据系列（`satisfactionRate` 趋势）
- [ ] 满意度系列使用右侧 Y 轴（`yAxisIndex: 1`），区间 [0, 100]
- [ ] 满意度系列使用不同颜色（如绿色虚线/实线）
- [ ] 左侧 Y 轴保留问答数量刻度
- [ ] 图表标题更新为「近7天问答趋势与满意度」
- [ ] `tooltip` 提示框同时显示问答数量和满意度百分比
- [ ] `legend` 图例新增「满意度」系列

### 2.2 新增反馈分布饼图（★）

- [ ] 新增反馈分布饼图（ECharts `pie` 类型）
- [ ] 数据来自 `todayPositiveCount` 和 `todayNegativeCount`
- [ ] 饼图扇区：正面反馈（👍 绿色）、负面反馈（👎 红色）
- [ ] 显示百分比标签
- [ ] `tooltip` 提示框显示具体数量
- [ ] 图表标题为「反馈分布」
- [ ] 如无反馈数据显示空状态（「暂无反馈数据」提示）

### 2.3 布局调整

- [ ] 图表区域布局：左侧趋势图（占 60% 宽度）+ 右侧反馈饼图 + 文档类型饼图（占 40% 宽度垂直排列）
- [ ] 或：趋势图全宽第一行，反馈饼图 + 文档类型饼图各半宽第二行
- [ ] 响应式考虑：小屏幕时图表堆叠排列

## 3. API 数据获取

### 3.1 Dashboard 数据获取

- [ ] `onMounted` 中调用 `statisticsApi.getDashboard()`
- [ ] 响应数据类型更新为新的 `DashboardVO`（含满意度字段）
- [ ] 解构新增字段：`todayPositiveCount`, `todayNegativeCount`, `satisfactionRate`
- [ ] 满意度数据处理（乘 100 转百分比、保留 1 位小数）
- [ ] 消息发送后考虑是否需要刷新仪表盘数据

### 4.1 仪表盘响应处理

- [ ] 新增 computed：`dashboardCards`（合并 7 个卡片的数据和元信息）

- [ ] 数字卡片使用千分位格式化（与 P1 保持一致）
