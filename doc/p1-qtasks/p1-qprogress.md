## 开发顺序

```
第 1 步：init       → 项目脚手架搭建
第 2 步：infra      → 基础设施层（API 客户端 + 路由 + 布局）
第 3 步：auth       → 认证模块（登录/注册 + 权限守卫）
第 4 步：chat       → 问答模块（核心功能）
第 5 步：knowledge  → 知识库管理（管理员）
第 6 步：user       → 用户管理（管理员）
第 7 步：dashboard  → 数据仪表盘（管理员）
```
